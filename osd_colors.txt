#
# OLED TV Optimization Notes:
#   - Outer background (screen_bg / background) is set to pure black (#000000)
#     so OLED pixels turn completely off (0% power burn-in, infinite contrast ratio).
#   - Container panels use ultra-dark cool tints (#04091A, #060F17, #0C061A, #021210).
#   - All text and active highlights use high-contrast cool-toned spectrums
#     (Cyan, Sapphire, Electric Violet, Mint, Glacier Ice, Metallic Steel).
#
# Value formats supported:
#   - Hex RGB888: #RRGGBB
#   - RGB888 triplet: r,g,b (0..255 each)
#   - RGB555 triplet: r,g,b (0..31 each)
#
